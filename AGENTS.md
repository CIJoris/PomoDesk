# PomoDesk working contract

## Vex operating contract

When working on Vex, read and follow `~/AGENTS.md` before any task.
That home file is authoritative for working preferences, change control,
verification, publication and routing actions to their proper logs.
Read applicable workspace and parent project contracts as well, including
ancestors above the Git root. This file adds project-specific rules; it does
not replace the home contract. These Vex-specific references do not require
access to Joris's home directory when working on another machine.

This repository owns PomoDesk, the ESP32-based physical Pomodoro timer.
Preserve existing source, design files and vendor material. Use the relevant
project documentation before changing implementation or hardware.
